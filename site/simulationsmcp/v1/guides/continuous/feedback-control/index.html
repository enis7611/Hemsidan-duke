🧭 Continuous (Value)

Feedback Control System

A continuous-time feedback control loop modeled with Value library blocks. A setpoint is compared against a measured output to compute an error signal, which drives a controller that adjusts the process input to minimize the error. Models PID controllers, thermostats, or any closed-loop regulation system.

Continuous (Value)

When to use this

  • Modeling a closed-loop control system (thermostat, speed controller, inventory level controller)
  • Analyzing control system stability, overshoot, and settling time
  • Designing or tuning PID controller gains for a simulated process
  • Modeling any system where an output is continuously measured and used to adjust an input
  • Evaluating control system response to disturbances or setpoint changes
Continuous (Value)

Blocks

BlockLibraryLabelPurpose
ConstantValue.lbrSetpointProvides the desired target value (setpoint) that the controller tries to achieve
MathValue.lbrErrorCalcComputes the error signal as (Setpoint - MeasuredOutput); provides the feedback comparison
EquationValue.lbrControllerImplements the control law (proportional, integral, or PID); takes error as input and outputs control action
Holding TankValue.lbrProcessIntegrates the control action over time to produce the process output (state variable); represents system dynamics
EquationValue.lbrFeedbackSensorReads the current Holding Tank level (process output) and feeds it back to the ErrorCalc block to close the loop

Key parameters

BlockParameterTypicalWhat it controls
Constant (Setpoint)value100 (target level, temperature, speed, etc.)The desired steady-state value the controller attempts to maintain. The controller drives error (Setpoint - Output) toward zero.
Equation (Controller)equationKp * e (proportional only) or Kp*e + Ki*integral(e) + Kd*derivative(e)The control law. Proportional-only (Kp*e) is simplest but may have steady-state offset. Add integral term (Ki) to eliminate offset. Add derivative term (Kd) to reduce overshoot. Typical Kp=1-10, Ki=0.01-0.1, Kd=0-1.
Holding Tankcapacity / initialLevelcapacity=1000, initialLevel=0 (or near setpoint)The Holding Tank acts as an integrator: its level changes at the rate set by the inflow (control action). Initial level sets the starting condition. Capacity must be large enough to accommodate the full operating range.
Mathequation (error = setpoint - feedback)V[0] - V[1]The error signal. Positive error means output is below setpoint (controller should increase input). Negative error means output is above setpoint (controller should decrease input or flow is reversed).
Continuous (Value)

Common mistakes

  • ⚠️ Forgetting to close the feedback loop by connecting the Holding Tank output back to the ErrorCalc block — without this connection the model is open-loop (no feedback); the output will drift without correction and the controller has no effect
  • ⚠️ Setting controller gain Kp too high — proportional gains that are too large cause oscillation or instability; start with a low gain (Kp=0.1) and increase gradually while observing the step response in the Holding Tank level
  • ⚠️ Using Equation block instead of Holding Tank for the process state — the process must be a dynamic element (integrator) to have meaningful control dynamics; an Equation block computes an algebraic (instantaneous) value, not a time-integrated state, which eliminates the dynamics the controller is designed to regulate
  • ⚠️ Not accounting for the sign of the feedback — if the Math block computes (Feedback - Setpoint) instead of (Setpoint - Feedback), the error signal is inverted and the controller drives the output in the wrong direction, causing instability; always verify error = setpoint minus measured output
Continuous (Value)

What to measure

📊

Settling time: time for Process output to reach within 5% of setpoint

📊

Overshoot: peak deviation above setpoint as percentage of setpoint value

📊

Steady-state error: remaining error after system settles (should be near zero with integral control)

📊

Rise time: time for output to go from 10% to 90% of final value

📊

Control effort: magnitude and variability of Controller output signal

Continuous (Value)

Variations

🔀

Proportional only (P controller)

Set Controller equation to Kp * error; accept small steady-state offset in exchange for simplicity and stability

🔀

PI controller (eliminate offset)

Add a second Holding Tank to integrate the error signal; add Ki * integral_error term to Controller equation to eliminate steady-state error

🔀

Tank level control →

Replace the Holding Tank Process block with actual Rate.lbr Tank+Valve blocks; feed Controller output to Valve goal connector to regulate tank level at setpoint
