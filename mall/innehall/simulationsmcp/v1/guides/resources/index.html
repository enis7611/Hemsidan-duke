Shared Resources →

Multiple processes compete for a limited pool of shared resources (operators, tools, vehicles). Each process requests resources when needed, uses them during processing, and releases them for other processes to use.

📘

Shift Schedule →

A model where processing capacity changes over time according to a work shift schedule. Activity capacity is linked to a Shift block that defines working hours, breaks, and off-shift periods. Models any operation with scheduled capacity variation.
