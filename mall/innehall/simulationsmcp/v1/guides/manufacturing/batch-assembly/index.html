Batch Assembly (Two-Component)

An assembly model where two separate component streams must be joined before the assembly operation. A Batch block holds components until one of each type is available, then combines them for processing. Models kitting, assembly, or any multi-input synchronization.

Manufacturing

When to use this

  • Modeling an assembly operation that requires one item from each of two or more component streams
  • Synchronizing multiple input streams before a combined processing step
  • Analyzing the impact of component imbalance on assembly throughput and WIP
  • Modeling kitting operations where a kit of parts must be assembled before production begins
  • Any scenario where items from multiple sources must be matched before proceeding

Key parameters

Common mistakes

  • ⚠️ Connecting component Create blocks directly to the Batch block without Queue buffers — the Batch block needs Queue blocks on each input because it pulls from Queue outputs, not directly from Create outputs; without Queues, components cannot accumulate and Batch will stall
  • ⚠️ Setting mismatched component arrival rates and not accounting for the resulting buffer imbalance — if component A arrives twice as fast as component B, the BufferA will grow indefinitely while BufferB stays near empty; always balance mean arrival rates across all component streams
  • ⚠️ Using temporary batch mode when permanent assembly is intended — temporary batching allows items to be unbatched later (via Unbatch block), which is wrong for assembly; use permanent batch mode when components are physically combined
  • ⚠️ Expecting Batch block throughput to exceed the rate of the slowest component stream — the assembly rate is limited by min(rateA, rateB); adding more Assembly Activities downstream cannot compensate for a slow component supplier

Variations

🔀

Three-component assembly

Add a third Create+Queue pair; connect third Queue to Batch third input. Batch waits for one item from each of three inputs before releasing

🔀

Variable batch size

Collect N identical items before processing (e.g., packaging): single Create→Queue→Batch with batchSize=N from one input

🔀

With serial line downstream →

Route assembled items through multiple processing stages after the Batch+Assembly step for post-assembly operations
