Manufacturing

  • Serial Production Line — A sequential manufacturing line where items pass through multiple processing stages in order, with a queue before each stage to buffer work-in-process. Models assembly lines, pipeline processes, or multi-step production flows.
  • Inspection and Rework Loop — A quality control pattern where items are inspected after processing and defective items are routed to a rework operation before returning for re-inspection. Models any feedback loop where failures are reprocessed.
  • Batch Assembly (Two-Component) — An assembly model where two separate component streams must be joined before the assembly operation. A Batch block holds components until one of each type is available, then combines them for processing. Models kitting, assembly, or any multi-input synchronization.
