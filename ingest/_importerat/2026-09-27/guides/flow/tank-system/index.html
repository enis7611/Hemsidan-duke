Guides / Continuous Flow (Rate)

Tank Pipeline System

A continuous flow model using Rate library blocks where material flows through a series of tanks connected by valves. Each tank stores fluid volume and each valve controls flow rate between tanks. Models liquid pipelines, chemical processes, or any continuous fluid system.

When to use this

  • Modeling continuous fluid or material flow (liquids, gases, bulk solids, chemicals)
  • Analyzing tank levels, overflow conditions, and flow rates in a pipeline
  • Simulating filling, draining, and steady-state flow in multi-tank systems
  • Modeling hydraulic systems, water distribution networks, or chemical processing
  • Any scenario where the quantity of interest is a continuously changing volume or rate

Blocks

BlockLibraryLabelPurpose
TankRate.lbrSourceTankFirst tank in the pipeline; represents the source or supply reservoir with initial fluid level
ValveRate.lbrValve1Controls flow rate from SourceTank to MidTank; rate can be fixed or controlled by a Value connector
TankRate.lbrMidTankIntermediate storage tank; level rises or falls based on inflow from Valve1 versus outflow through Valve2
ValveRate.lbrValve2Controls flow rate from MidTank to SinkTank; enables independent control of each pipeline segment
TankRate.lbrSinkTankTerminal receiving tank; accumulates material flowing through the system

Connections

  • SourceTank (FlowOut) → Valve1 (FlowIn)
  • Valve1 (FlowOut) → MidTank (FlowIn)
  • MidTank (FlowOut) → Valve2 (FlowIn)
  • Valve2 (FlowOut) → SinkTank (FlowIn)

Key parameters

BlockParameterTypicalWhat it controls
Tankcapacity / initialLevelcapacity=1000 units, initialLevel=500 units (50% full)Tank capacity sets the maximum volume. Initial level determines starting conditions. When level hits capacity, tank overflows; when level hits 0, tank empties and downstream valves close automatically.
ValvemaxRate / goalmaxRate=100 units/hour, goal=100 (constant flow)maxRate sets the maximum possible flow rate. goal sets the desired flow rate. Actual flow is min(goal, available flow from upstream, capacity in downstream). Connect a Value connector to goal for dynamic control.
TankmaxInputRate / maxOutputRate0 (unlimited) or pipe capacity limitPhysical rate limits at the tank inlet and outlet. Set to 0 to allow unlimited flow rate (limited only by connected valves). Use to model pipe capacity constraints.
Valvegoal (via Value connector)Equation block output or Constant blockFor dynamic valve control, connect an Equation or Constant Value.lbr block to the Valve goal connector. This enables level-based control, schedules, or feedback regulation.

Common mistakes

  • Mixing Rate.lbr blocks with Item.lbr blocks in the same flow path — Tank and Valve are Rate library blocks and connect via flow connectors (not item connectors); attempting to connect a Create or Activity block directly to a Tank will fail; keep discrete item flow and continuous flow in separate model sections
  • Setting Valve maxRate higher than the Tank's maxOutputRate or the upstream Tank's available volume — the valve cannot push more flow than physically possible; actual flow is always limited by the most constrained element in the path
  • Not setting initial Tank levels — if all tanks start empty and the source tank has no inflow, the model starts with zero flow; set SourceTank initialLevel to a realistic starting value to avoid a trivially empty simulation
  • Forgetting that when a Tank empties, downstream valves automatically reduce to zero flow — this is correct physical behavior but can be mistaken for a model error; verify tank levels before investigating unexpected flow shutdowns

What to measure

  • Tank level over time for each tank (fill/drain curves)
  • Flow rate through each valve (actual versus requested)
  • Time to empty or fill each tank under current flow rates
  • Overflow events (when any tank reaches capacity)
  • Steady-state flow rate through the system (when inflow equals outflow)
